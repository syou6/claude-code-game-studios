# Game Brief: ポケットアイランド

**One-sentence pitch:** 毎回形の変わる小さな島を掘り進め、潮が満ちる前に宝を抱えて舟へ戻る、5分で一周のローグライク宝探し。

## Core loop
- 島に上陸し、地図の手がかりを見て掘る場所を決める
- 掘ると宝・道具・罠のどれかが出る。道具で掘れる範囲や速さが伸びる
- 潮位ゲージが上がりきる前に舟へ戻る。戻れたぶんの宝だけが持ち帰れる

## Player goal & fail state — what "working" looks like
- 目標: 潮が満ちる前に舟へ戻り、持ち帰った宝の合計スコアを伸ばす
- 失敗: 潮位ゲージが満ちた時点で舟にいなければ、その回の宝はすべて失い、島はリセットされる

## MVP — what must exist to be the game
- 手続き生成される小さな島(格子状、毎回地形と宝の配置が変わる)
- 掘るアクション(1タイルを掘ると中身が判明する)
- 潮位タイマーと、満潮時の失敗判定
- 3種類の宝(価値が異なる)と、1種類の罠(時間を奪う)
- 1種類の道具(掘れる範囲が広がるシャベル強化)
- 舟への帰還による回収とスコア表示
- リスタート(即座に次の島へ)

## Out of scope — not building this
- セーブデータ・永続強化(メタ進行)なし
- 敵キャラ・戦闘なし
- 複数ステージ・ワールドマップなし
- マルチプレイなし
- ストーリー・NPC なし

## Build order
1. 格子状の島生成と「掘る」操作: 掘って中身が出る瞬間が面白いかを最初に確かめる
2. 潮位タイマーと帰還判定: 時間圧が「もう1タイル掘るか戻るか」の緊張を生むか試す
3. 宝3種・罠1種・道具1種: 掘る判断に意味を持たせる
4. スコア表示とリスタート: 1周が5分で回ることを確認する

---
**Who it's for / what they feel:** 通勤や休憩の隙間に遊ぶカジュアルゲーマー。「あと1回だけ」と思わせる欲と緊張のシーソー。

**Art & audio direction:** 明るいローポリ風ドット絵、波音とマリンバの軽いループ、掘るたびに小気味よい効果音。

**Reference game:** Spelunky の「降りるか戻るか」の判断を、戦闘なしで潮タイマーだけに絞ったもの。Minesweeper の「1マスずつ開ける」手触りを掘削に転用。
